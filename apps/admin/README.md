# لوحة الإدارة (Admin Web)

تطبيق صفحة واحدة بالعربية (RTL) **بلا خطوة بناء ولا مكتبات**: ملفات HTML/CSS/JS عادية (ES modules) تعمل مباشرة من أي خادم ملفات. تتحدث مع الـ API نفسه على نفس النطاق (`/api/v1`).

## التشغيل
- **الإنتاج:** `docker-compose.prod.yml` يجعل Caddy يخدم هذا المجلد على `/` والـ API على `/api` من نطاق واحد (لا CORS).
- **محلياً مع API حقيقي:** `python3 -m http.server 3001 --directory apps/admin` ثم عدّل `config.js` إلى `{ apiBase: 'http://localhost:3000/api/v1' }` وأضف `http://localhost:3001` إلى `CORS_ORIGINS` في `.env`.
- **تجربة بلا API:** `node apps/admin/test/mock-api.cjs` (خادم تجريبي + الواجهة على `http://127.0.0.1:4010`؛ المستخدم `admin` / كلمة المرور `Admin#12345`).

## الشاشات
لوحة المتابعة · العملاء (+كشف الحساب والفواتير المفتوحة والإسناد) · الطلبات (اعتماد/تجهيز/تحويل لفاتورة/إلغاء) · الفواتير (إنشاء/عرض/إلغاء) · المردودات (مع **تقدير** سياسة البونص قبل الإرسال) · التسديدات (توزيع تلقائي/على فاتورة/إلغاء) · المنتجات · أرصدة المخزون · التشغيلات والصلاحية · المشتريات (إنشاء/استلام بالتشغيلات) · التحويل بين المخازن · تسويات المخزون · الشركات · التصنيفات · المخازن · المناطق (إسناد/نقل) · المندوبون · قوائم الأسعار · قواعد البونص · **التقارير (21 تقريراً + تصدير CSV)** · طابور المزامنة (إعادة/تجاهل) · المستخدمون والأجهزة · سجل التدقيق · الإعدادات · الإشعارات.

## الأمان
- كل نص قادم من الخادم يُعرض عبر `textContent` (لا `innerHTML` في أي مكان): اسم عميل مثل `<img onerror=…>` يظهر نصاً ولا يُنفَّذ (مُختبَر).
- سياسة CSP صارمة في `index.html`: لا سكربتات ولا أنماط inline ولا اتصال إلا بنفس النطاق.
- الرموز في `sessionStorage` (تُمحى بإغلاق التبويب) مع تجديد تلقائي عند الانتهاء. **هذا يعني أن أي ثغرة XSS مستقبلية تكشف الرمز؛ لذلك CSP والـ textContent إلزاميان — لا تضف `innerHTML` أبداً.**
- القائمة والصفحات تُخفى حسب الصلاحية، لكن **الخادم هو الذي يفرضها** دائماً.

## الاختبار
```bash
node apps/admin/test/logic.test.mjs        # معاينة البونص/المردود تطابق قواعد الخادم (16 تأكيداً)
cd apps/admin && npm i --no-save playwright && npx playwright install chromium
node test/ui.test.cjs                      # 30 فحصاً في Chromium حقيقي ضد الخادم التجريبي
```
**مهم:** الاختبارات تثبت أن الواجهة تعمل **مع الخادم التجريبي**؛ أما مطابقتها للـ API الحقيقي (أشكال الاستجابة وأسماء الحقول) فلم تُجرَّب بعد ← جرّب كل شاشة على النسخة التجريبية الحقيقية.
