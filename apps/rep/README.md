# تطبيق المندوب (PWA)

صفحة ويب تُثبَّت على أندرويد («إضافة إلى الشاشة الرئيسية») وتعمل **دون إنترنت**. بلا بناء ولا مكتبات (ES modules). على نفس نطاق الـ API: `https://النطاق/rep/` (Caddy يخدمه).

## ما تفعله
- الدخول (مع تغيير كلمة المرور المؤقتة)، وتبقى الجلسة بين الفتحات.
- **خطة اليوم** وتخطّي الزيارة (يحتاج اتصالاً)، **العملاء** (بحث عربي مُطبَّع) والرصيد والفواتير المفتوحة.
- **زيارة** (مع التقاط الموقع GPS والدقة)، **طلب** (سعر قائمة العميل + معاينة البونص محلياً)، **تسديد**، **مردود** (اختيار الفاتورة يحتاج اتصالاً).
- كل عملية تُحفظ أولاً في IndexedDB (outbox) بمعرّف `localId` ثم تُرسل عبر `POST /sync/push`؛ إعادة الإرسال آمنة (لا تكرار). المزامنة تلقائية عند عودة الشبكة وكل دقيقتين وزر «مزامنة الآن».
- التعارضات/المرفوضات تظهر للمندوب ولا تُفقد (تبقى عند الإدارة في «طابور المزامنة»).
- تنزيل Delta لكل الكيانات حسب `docs/PHASE_8_STATUS.md`، مع تحقق `itemCount` لقوائم الأسعار.

## قرارات يجب أن تعرفها
- الرموز في `localStorage` (لازمة للعمل دون إنترنت). لذلك CSP صارمة ولا `innerHTML` أبداً.
- الخروج يمسح بيانات الجهاز؛ ويُحذَّر إن وُجدت عمليات غير مرسلة. دخول مستخدم آخر على الجهاز يمسح بيانات السابق.
- Service Worker بلا `skipWaiting`: الإصدار الجديد يعمل عند إغلاق التطبيق وفتحه (لا خلط ملفات). عدّل `VERSION` في `sw.js` وقائمة `SHELL` عند إضافة ملف.
- `x-platform: web`: حدّ «الإصدار الأدنى» في الإعدادات (`app_versions`) يخصّ android/ios فقط ولا يشمل هذا التطبيق.
- المعاينة المحلية للسعر/البونص **تقديرية**؛ الخادم يحسب النهائي.

## ما ليس فيه
تعديل/إنشاء عملاء دون إنترنت · تخطّي الخطة دون إنترنت · كشف حساب العميل (يحتاج الخادم) · إشعارات Push · عرض خريطة. **لم يُجرَّب على الـ API الحقيقي ولا على هاتف فعلي.**

## الاختبار
```bash
node apps/rep/test/pricing.test.mjs                 # السعر/البونص + تطابق logic.js مع الإدارة
npm i --no-save playwright && npx playwright install chromium
node apps/rep/test/ui.test.cjs                      # 12 فحصاً في Chromium: دخول، مزامنة، offline، إعادة إرسال، تعارض، مردود
```
