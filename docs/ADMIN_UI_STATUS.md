## كيف تتحقق على الـ API الحقيقي
1. شغّل الـ API وسجّل الدخول من المتصفح بحساب Super Admin، وامرّ على كل شاشة في القائمة: كل شاشة يجب أن تعرض بيانات أو «لا توجد بيانات»، ولا رسائل خطأ حمراء.
2. نفّذ بالواجهة نفسها السيناريو الأساسي: عميل ← إسناد ← شركة/منتج/مخزن ← شراء واستلام ← قاعدة بونص ← فاتورة ← تسديد ← مردود ← تقرير ← CSV.
3. افتح أدوات المطوّر (Console): يجب ألا تظهر أخطاء حمراء ولا انتهاكات CSP.
4. أرسل لي أي شاشة تخالف المتوقع (لقطة + ما فعلته).
